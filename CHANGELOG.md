# Changelog — Pop!

Toutes les modifications notables de ce projet sont documentées dans ce fichier.

Le format suit l’esprit de Keep a Changelog et le projet utilise un versionnage sémantique.

## [1.0.0] — 18-08-2026

### Première version stable

- création de la mindmap à révélation progressive ;
- sujet central puis quatre niveaux d’associations ;
- branches et cellules du dernier niveau différenciées par groupes de couleurs ;
- zoom tactile et bureau, déplacement de la carte et vue entière ;
- confirmation avant suppression d’une branche comportant des descendants ;
- conservation des descendants lors d’une simple modification du terme parent ;
- espace **Termes** pour récupérer les contenus de la mindmap ;
- vue simple des termes sélectionnée par défaut ;
- vue liste pour l’organisation ;
- tri A→Z, Z→A, du plus long au plus court et du plus court au plus long ;
- réorganisation manuelle des termes ;
- création et suppression de groupes ;
- masquage et réaffichage des termes ;
- espace **Idées** avec création, édition, suppression et bibliothèque ;
- action permanente **✦ Nouvelle idée** ;
- annuler / rétablir et raccourcis clavier associés ;
- nom du travail ;
- sauvegarde locale automatique ;
- sauvegarde externe sous la forme `pop_nomduprojet.json` ;
- ouverture de projets Pop! ;
- compatibilité d’import avec les premières sauvegardes de développement ;
- impression des termes en présentation fluide sans cellules ;
- impression des idées ;
- styles Jour, Nocturne et Licorne ;
- interface bilingue français / anglais ;
- manuel intégré bilingue ;
- interface responsive pour ordinateur, tablette et téléphone ;
- favicon `favicon/favpop.png` et icône Apple ;
- footer Eigrutel BD Academy ;
- nettoyage et commentaires du code en français et en anglais ;
- publication sous AGPL-3.0-or-later pour le code et CC BY-SA 4.0 pour la documentation et les modèles.
